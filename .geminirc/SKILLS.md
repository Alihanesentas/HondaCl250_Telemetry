# AGENT SKILLS & TECHNICAL COMPETENCIES

## 1. EMBEDDED & AUTOMOTIVE FIRMWARE
- **Microcontrollers**: ESP32-S3 (Xtensa LX7 Dual-Core, FreeRTOS).
- **Automotive Protocols**: CAN Bus (ISO 11898-1), UDS Diagnostic Protocol (ISO 14229), OBD-II.
- **Peripherals & Buses**: ESP32 TWAI (Two-Wire Automotive Interface), HardwareSerial (UART), Wire (I2C Fast Mode 400kHz), SPI.
- **Sensors**: MPU6050 Accelerometer/Gyroscope, Complementary Filtering, Euler Angle Dynamics.

## 2. WIRELESS & COMMUNICATIONS
- **Bluetooth Low Energy (BLE)**: ESP32 BLE Server, GATT Services/Characteristics, Custom Notifications, 12-byte packed binary buffers.
- **Wi-Fi Networking**: SoftAP Mode, WebServer HTTP endpoints, CORS configuration, JSON serialization.

## 3. MOBILE & FRONTEND DEVELOPMENT
- **Flutter / Dart**: Cross-platform mobile development, `flutter_blue_plus`, `permission_handler`, reactive UI states.
- **Web Bluetooth & PWA**: HTML5, Vanilla CSS3 (Dark Cockpit aesthetic), JavaScript Web Bluetooth API, SVG gauge animations.

## 4. ARCHITECTURAL PATTERNS
- **Object-Oriented C++**: Polymorphism, Pure Virtual Interfaces (`IModule`), Thread-Safe Shared State (`SystemState`), Time-Slicing Non-Blocking Event Loop.
